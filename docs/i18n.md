# i18n (internationalisation)

Notai uses [`next-intl`](https://next-intl.dev) with a **cookie-based**
locale (no URL prefix). Messages live in `apps/web/messages/<locale>.json`.

## Active locales

| Code | Language | Native name |
| ---- | -------- | ----------- |
| `en` | English  | English     |
| `ro` | Romanian | Română      |

The default fallback is `en`.

## How locale is resolved

1. The `notai_locale` cookie (set when the user picks one in
   `/app/settings/security`).
2. Otherwise, the first acceptable language from the `Accept-Language`
   request header.
3. Otherwise, `en`.

This logic lives in `apps/web/i18n.ts` (`resolveLocale()`).

## Adding strings

1. Add the key to **every** `messages/<locale>.json` file (always add to
   `en.json` first; missing keys in other locales fall back to the key
   itself, which is loud and easy to spot).
2. Use the namespace as a prefix:

   ```ts
   // server component
   import { getTranslations } from 'next-intl/server';
   const t = await getTranslations('auth');
   t('welcomeBack');

   // client component
   import { useTranslations } from 'next-intl';
   const t = useTranslations('auth');
   ```

## Adding a new locale

1. Add the code to `SUPPORTED_LOCALES` in `apps/web/i18n.ts`.
2. Copy `messages/en.json` → `messages/<code>.json` and translate.
3. Add an `<option>` to `LocaleSwitcher` (`apps/web/src/components/settings/locale-switcher.tsx`).
4. Update this doc.

## What is NOT translated

- **Note content** — never translated.
- **API responses** — error messages from `/api/*` remain in English so
  third-party consumers can rely on stable strings.
- **Email templates** — currently English-only. Translating these is a
  separate slice (TODO, tracked under `docs/competitive-analysis.md`).

## Development tips

- Restart the dev server after editing `messages/*.json` (Next caches
  the import).
- Romanian diacritics (`ă`, `â`, `î`, `ș`, `ț`) must be saved as UTF-8
  with no BOM — every editor in this repo is configured for that via
  `.editorconfig`.
- The cookie is `SameSite=Lax`, `Secure` in production, with a 1-year
  TTL.
